# Day 5 – Loops & Password Generator

## Overview
This day focused on mastering iteration in Python using `for` loops and the `range()` function. These concepts were applied through classic programming exercises and a password generator project with multiple difficulty levels.

## Concepts Covered

### For Loops
Learned how to repeat a block of code multiple times using Python's `for` loop.

### Range Function
Explored the `range()` function for generating sequences of numbers and controlling loop iterations.

### Indentation
Understood the importance of proper indentation in Python and how it defines the scope of loops and other code blocks.

## Exercises

### FizzBuzz
Implemented the classic FizzBuzz problem using a `for` loop.

Rules:
- Print `"Fizz"` for numbers divisible by 3.
- Print `"Buzz"` for numbers divisible by 5.
- Print `"FizzBuzz"` for numbers divisible by both 3 and 5.
- Otherwise, print the number itself.

This exercise helped strengthen understanding of loops, conditionals, and modulo operations.
