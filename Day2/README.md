# Day 2 – Python Basics Continued

## Overview
This day focuses on understanding Python data types, type conversion, operators, and formatting techniques. A small project (Tip Calculator) was also built to apply these concepts in practice.

## Concepts Covered

### Type Errors
Learned what type errors are and why they occur when incompatible data types are used together.

### Type Conversion / Type Casting
Understood how to convert one data type into another using functions like:
- `int()`
- `float()`
- `str()`

### Data Types
Explored different built-in data types in Python such as:
- Integer
- Float
- String
- Boolean

### Operators
Studied basic arithmetic operators and their behavior in expressions.

### Division Types
Understood the difference between:
- `/` → Floating point division
- `//` → Floor division (removes decimal part)

### PEMDAS Rule
Learned the order of operations in Python:
Parentheses → Exponents → Multiplication/Division → Addition/Subtraction

### Rounding Off
Practiced rounding numbers to custom decimal places using the `round()` function.

### F-Strings
Learned formatted string literals for cleaner and more readable output.

## Mini Project – Tip Calculator

Built a program that:
- Takes bill amount as input
- Takes tip percentage
- Takes number of people splitting the bill
- Calculates and displays how much each person should pay

## Summary
This session strengthened understanding of Python fundamentals and introduced practical problem-solving through a real-world mini project.
