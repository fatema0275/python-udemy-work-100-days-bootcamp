# Day 3 – Conditional Statements & Mini Projects

## Overview
This day focuses on decision-making in Python using conditional statements. Learned how programs can take different paths based on user input using `if`, `elif`, and `else`. Also explored logical operators and applied them in multiple small projects.

## Concepts Covered

### Conditional Statements
Learned how to control program flow using:
- `if`
- `else`
- `elif`

### Nested If-Else
Understood how conditions can be placed inside other conditions for multi-level decision making.

### Logical Operators
Used logical operators to combine conditions:
- `and` → All conditions must be true
- `or` → At least one condition must be true
- `not` → Reverses a condition

## Mini Projects

### 1. Theme Park Bill Calculator
Built a program that:
- Checks user height eligibility
- Takes age input to determine ticket price category
- Offers optional photo purchase
- Calculates and displays final bill

This project simulates real-world decision-based pricing systems.

---

### 2. Pizza Price Calculator
Created a system that calculates pizza cost based on:
- Size (S / M / L)
- Pepperoni add-on
- Extra cheese option

Final bill is generated dynamically based on user choices.

---

### 3. Treasure Hunt Game
Developed a simple text-based adventure game using:
- ASCII art for visuals
- Conditional logic for choices
- Multiple decision paths leading to win/lose outcomes

## Summary
This day strengthened understanding of decision-making in Python. Built multiple interactive programs that simulate real-world logic systems using conditional statements and operators.
