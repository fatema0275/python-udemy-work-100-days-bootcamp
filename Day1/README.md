# Day 1 – Python Basics

## Overview
This day covers the fundamental basics of Python programming, including output, variables, string manipulation, and taking user input.

## Concepts Covered

### Print Function
Learned how to display output using the `print()` function in Python.

### Variables
Understood how variables are used to store and manage data values.

### String Manipulation
Practiced combining strings using concatenation to form meaningful output.

### Input Function
Learned how to take input from the user using the `input()` function and store it in variables.

## Summary
This session builds the foundation of Python programming by introducing basic input/output operations, variables, and string handling.
