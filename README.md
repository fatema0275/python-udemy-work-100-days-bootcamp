# 100 Days of Python – Learning Journey

## Overview
This repository documents my 100-day structured learning journey in Python programming. The goal is to build strong fundamentals in programming, problem-solving, and software development through consistent daily practice.

Each day includes:
- Core concepts learned
- Small practice programs
- Mini projects to apply the concepts

## Purpose
The main objectives of this repository are:
- Strengthen Python fundamentals
- Improve logical thinking and problem-solving skills
- Build confidence through hands-on coding
- Develop consistency through daily practice
- Create a portfolio of beginner-to-intermediate Python projects
