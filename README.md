# Day 4 – Random Module & Lists

## Overview
This day focuses on generating randomness in Python using the `random` module and working with lists as a fundamental data structure. Concepts were reinforced through an interactive Rock Paper Scissors game.

## Concepts Covered

### Random Module
Learned how to generate random values using Python’s built-in `random` module:
- `random.randint(a, b)` → generates a random integer within a range
- `random.uniform(a, b)` → generates a floating-point number within a range
- `random.random()` → generates a float between 0 and 1

### Lists in Python
Studied list operations and manipulation techniques:
- `append()` → add element at the end
- `pop()` → remove element by index
- `remove()` → remove element by value
- `insert()` → insert element at a specific position
- Indexing and slicing
- Nested lists (lists inside lists)

## Mini Project – Rock Paper Scissors Game

Built an interactive Rock Paper Scissors game that includes:
- User input handling
- Random computer choice using `random` module
- ASCII art for visual representation of choices
- Game logic using conditional statements
- Winner determination based on standard rules

## Summary
This day improved understanding of randomness and list manipulation in Python. The Rock Paper Scissors game helped combine multiple concepts like conditionals, lists, randomization, and user interaction into a single working program.
